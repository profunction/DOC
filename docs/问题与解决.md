## 四、指纹和面容（Android）

- **指纹**：几乎所有 Android 手机都能给 App 用。
- **面容**：很多 Android 手机的面容只能解锁屏幕，不开放给 App；Pixel、部分华为荣耀等可以。
- **都没有时**：用手机自己的锁屏密码、图案或 PIN。
- 开启方式：在手机上第一次用密码登录后会问你；或在「我的」里打开「用指纹 / 面容解锁」。离开 App 超过 5 分钟回来要再验证。长者手机不上锁。

## 五、长者手机怎么设置（一次就好）

1. 在父母手机装安心照顾 App。
2. 子女在自己的 App →「健康档案」→「生成父母手机的启用码」。
3. 父母手机用相机扫二维码（或在 App 点「我有启用码」输入），点「在这台手机启用长者端」。
4. 自动弹出「长者手机设置」：点「设为手机桌面」，在系统画面选「安心照顾」→「始终」；再点「屏幕常亮」。
5. 以后要改设置：按住「您好，xxx」3 秒。
