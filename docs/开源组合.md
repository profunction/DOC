# 第一阶段零开发的开源组合

计划书第六节建议第一阶段"不用做 App"。下面这套全部是部署即用的开源软件，一台 2 核 4G 的 VPS 就够。

| 需求 | 软件 | 许可 | 作用 |
|---|---|---|---|
| 一个 WhatsApp 号码对外、多人值班 | Chatwoot | MIT | 共享收件箱、分配、标签。需要 Meta 商业账号开通 WhatsApp Business API。 |
| 健康档案、合作伙伴名单、付费表 | Baserow | MIT | 自托管 Airtable，表单 + 权限，资料留在自己服务器。 |
| 照顾人上门填探访报告 | KoboCollect / ODK Collect | Apache-2.0 | 安卓离线表单，带照片、GPS，回到有网自动上传。 |
| 手表定位、SOS、围栏 | Traccar | Apache-2.0 | 支持大量 4G 定位手表；网页地图 + 手机 App，可给子女开账号。 |
| 协调员手机收警报 | ntfy | Apache-2.0 | 自托管推送；Traccar / Baserow 的事件推到手机。 |
| 提醒吃药（装在老人手机） | MedTimer / PillSOS | MIT / GPL-3 | 离线、无广告，F-Droid 下载。 |
| 把以上串起来 | n8n | fair-code（自用免费） | Baserow 新纪录 → WhatsApp 讯息 → ntfy 推送。 |

三十个客人以后，再把本仓库的 App 接到同一批数据上：Traccar 事件已可直接进本系统（`/api/integrations/traccar`），Chatwoot 与 Baserow 都有 API。
