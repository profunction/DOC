# 一步一步：从现在到正式营业

每一步写明"谁做、要多久、做完的标志"。按顺序做，不要跳。

## 第 1 周：把服务器变成正式的

1. **升级 Render**（你，10 分钟）：anxin-care → Settings → Instance Type 选 Starter；Disks 加 1 GB 挂 `/var/data`；Environment 设 `DATA_DIR=/var/data`、`SEED_DEMO=0`。做完标志：登录页没有"演示账号"。
2. **打开紧急推送**（你，10 分钟）：用你的号登录协调员端 → 设置 → ntfy「随机生成」→ 保存；手机装 ntfy App 订阅同一主题；点「发测试推送」，手机响了就对。
3. **填真实热线**（你，1 分钟）：同一个设置页。
4. **下载一份备份**（你，1 分钟）：设置页「马上备份」→ 下载，存到电脑。以后每周一次。

## 第 2 周：公司与法律（可以和第 1 周同时）

5. 注册 Sdn Bhd，申请 D-U-N-S 编码（要等约一个月，所以最早办）。
6. 找律师改三份文件：服务合约、隐私政策（`/legal` 页的模板）、免责声明。
7. 买公众责任险。

## 第 3 周：试用

8. 找 3 位长者 + 3 位子女 + 1 位照顾人试用一周。子女自己注册，你「确认开通」；长者手机扫码设置成桌面模式。
9. 每天问他们"哪里卡住了"，截图发我，我改。

## 第 4 到 5 周：上架

10. Google Play 开发者账号（25 美元），用公司身份注册；填健康类声明、资料安全表、隐私政策网址（我可以把文案准备好）。
11. 个人账号要 12 人封闭测试 14 天：把试用的人和朋友都拉进来。
12. 上架后把网站"下载 App"改成 Play 商店链接。

## 第 6 周起：手表与收款

13. 买 VPS，跑 `deploy/install-vps.sh`（见手表指南），买 3 到 5 只样品手表实测。
14. 申请 Billplz 或 ToyyibPay（FPX / DuitNow）商户，给我商户密钥，我接在线付款。
15. 开 Firebase 项目（免费），把 `google-services.json` 和服务账号 JSON 给我，子女 App 关着也能收推送。
