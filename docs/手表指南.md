# 智能手表：怎么买、怎么接、怎么用

## 一、买什么手表

**必须满足的条件（问工厂时一条一条确认）**

1. 4G 插卡，GPS 定位，SOS 按钮，可通话，防水。
2. **能把服务器地址改成我们自己的**（IP 或域名 + 端口）。这是最关键的一条。只能用工厂 App（如 SeTracker）的手表不要买。
3. 使用 **"watch" 协议**（市面上大多数中国产儿童 / 长者 4G 手表都是这个协议，Traccar 端口 5093）。让工厂给协议文档，或直接说"支持 Traccar"。
4. 跌倒感应、心率：有最好，但要实测。问工厂：跌倒警报是以什么指令发出的（AL / fall down）。
5. 先寄 3 到 5 只样品。

**参考价**：基本款约 26 到 35 美元；带跌倒感应约 98 到 110 美元；另加每只每月一张 SIM 卡（马来西亚预付卡约 RM 10 到 20）。

**进口**：4G 设备要通过 MCMC / SIRIM 认证，批量进口前先问货代或认证代理。

## 二、服务器怎么搭（一条命令）

手表要连的是一个 TCP 端口，Render 这类平台不开放，所以要一台 VPS（DigitalOcean / Vultr 新加坡节点，约 6 美元一个月）。

1. 买 VPS 选 Ubuntu 24.04，拿到 IP。
2. 把域名（例如 care.你的域名.com）指向这个 IP。
3. SSH 进去，执行：

```bash
curl -fsSL https://raw.githubusercontent.com/profunction/doc/claude/new-session-1skmg3/deploy/install-vps.sh -o install.sh
```

```bash
bash install.sh care.你的域名.com
```

脚本会装 Docker、下载代码、生成密钥、启动本系统 + Traccar + ntfy、配好 HTTPS。最后会打印出 Traccar 后台地址、手表要填的服务器和端口、ntfy 主题和协调员账号。

4. 开防火墙：放行 80、443，以及 5093（watch 协议）。其他品牌的端口查 Traccar 文档的端口表。

## 三、手表怎么设置

1. 插 SIM 卡，开机。
2. 用手表的设置短信把服务器指到我们这里（各品牌指令不同，常见格式）：

```text
pw,123456,ip,care.你的域名.com,5093#
```

3. 登录 Traccar 后台（`https://care.你的域名.com/traccar`，首次 admin / admin，马上改密码），新增设备，Identifier 填手表的 IMEI。
4. 在安心照顾协调员端 →「客人」→ 编辑 → 「智能手表」填同一个 IMEI。
5. 回到「手表」页，看到最后信号和电量就是接通了。

## 四、安心照顾会自动做的事

| 手表发生 | 系统反应 |
|---|---|
| 按 SOS | 协调员页面弹警报、协调员手机 ntfy 响、子女 App 推送、家庭群组留痕 |
| 跌倒 | 同上（跌倒警报） |
| 走出安全范围 | 子女或协调员在「父母位置」设好家的位置和距离（如 300 米）后，走出去即报警；回到范围内不重复报 |
| 电量低于 20% | 提醒一次 |
| 心跳低于 45 或高于 120（可改） | 提醒 |
| 超过 6 小时没信号 | "手表没信号"警报（每 15 分钟检查一次） |
| 手表被摘下 | 警报（手表支持才有） |

子女端「父母位置」显示：最后信号时间、电量、心率、是否在安全范围、最近 24 小时轨迹小图，一键打开地图。

## 五、拿到样品后的测试清单

- [ ] 手表在 Traccar 后台出现位置
- [ ] 安心照顾「手表」页出现最后信号和电量
- [ ] 按 SOS，10 秒内协调员手机响
- [ ] 把手表放桌上拍一下 / 模拟跌倒，看有没有跌倒警报（不是每款都准）
- [ ] 带手表走出 300 米，收到"走出安全范围"
- [ ] 关机 6 小时后收到"没信号"
- [ ] 戴一天看电池能撑多久

协调员端「手表」页有「模拟」按钮，没有真手表也可以先看整条流程怎么走。
