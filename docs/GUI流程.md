# GUI 流程：每个人打开 App 后一步一步会看到什么

原则：**一个人一次只做一件事**。不让用户在十个标签里找，而是按事情发生的顺序把人带过去。下面每条流程，箭头右边就是下一个画面。

## 1. 子女（在新加坡上班的女儿 / 儿子）

### 第一次使用
```
下载 App → 登录页 → [注册账号]
  → 填自己（姓名、手机、密码）
  → 填父母（关系、称呼、出生年、地区、地址、病史）
  → 勾同意 → [注册]
  → 直接进入「总览」（顶部黄条：服务尚未正式开通，可一键 WhatsApp 协调员）
  → 协调员确认后黄条消失，群组收到"已开通"
```

### 设置父母的手机（一次）
```
总览 → 更多 → 健康档案 → [生成父母手机的启用码] → 出现二维码
  → 父母手机装 App → 相机扫码 → [在这台手机启用长者端]
  → 自动弹「长者手机设置」→ [设为手机桌面] → 系统选"安心照顾 / 始终" → [屏幕常亮] → 关闭
```

### 每天打开看一眼
```
总览：顶部有没有红色横幅（处理中的事件）
  → 今天的安排（谁几点来）
  → 最近一次探访（精神、血压、吃药，点开看照片）
  → 父母位置（更多 → 父母位置：在不在安全范围、电量、最后信号）
```

### 出事的时候
```
手机推送 / ntfy 响 → 打开 App → 红色横幅 → 点进「紧急事件」
  → 看到协调员每一步（回电、派人、到场、结案），时间线实时更新
  → 家庭群组里可以直接问协调员
```

### 要预约服务
```
预约服务 → 选类型（陪诊 / 探访 / 买药 …）→ 选时间 → 写说明 → [提交]
  → 列表显示"待安排" → 协调员安排后变"已安排"并显示谁负责 → 完成后变"已完成"，报告出现在「探访报告」
```

## 2. 长者

### 唯一的画面（三个按钮）
```
开机 → 直接是安心照顾（桌面模式）
  [紧急求助]（按住 2 秒）→ "已通知，协调员会在三分钟内回电" → 状态自动变：已接手 → 已派人 → 已结案
       没网时 → [打给协调中心] / [发短信求助]（短信自带位置）
  [我要找人] → 打电话 / WhatsApp / 第二联络人
  [看今天的安排] → 谁几点来
```
家人要改设置：按住"您好，xxx"3 秒。

## 3. 协调员

### 每天早上
```
登录 → 总览「今天要处理」
  → 待确认的新注册 → [确认开通]（先打电话核实）
  → 待安排的预约 → [安排] → 派单页选照顾人 / 合作伙伴
  → 今天任务按时间排好
```

### 警报来了
```
ntfy 响 / 页面弹红条 → 紧急事件
  → [打电话 阿婆] → 判断轻重
  → 轻症：[派护士 / 医生上门] 或 [派照顾人上门]
  → 重症：[叫救护车（999 / 私人）]
  → 每一步在输入框记一句 → [记录处理步骤]
  → 处理完 → 写结果 → [结案]（子女端同步看到）
```

### 新客人进来（三种入口，同一个出口）
```
网站表格 / App 注册 / WhatsApp 来电
  → 申请与注册 页 → 回电、签约、拿同意书
  → 客人页建档（或确认注册者自建的档案）
  → 账号页开长者 / 照顾人账号（子女已自助注册的不用）
  → 手表到了：客人档案填 IMEI → 手表页看信号
```

### 手表
```
手表 → 选客人 → 看最后信号 / 电量 / 状态
  → 设安全范围（用档案地址 或 手表现在位置 + 距离）
  → [模拟] 测整条流程
```

## 4. 照顾人

```
登录 → 我的任务（今天 / 接下来）
  → 出发前：[客人资料]（病史、过敏、家属电话）、[导航]
  → 到了：[开始]
  → 做完：[完成并填报告] → 点选精神 / 吃药 / 饮食 / 安全 → 拍照 → [提交]
  → 任务自动完成，子女即时收到
```

## 5. 现在的画面和这些流程对得上吗

| 流程 | 现在的 App | 还差什么 |
|---|---|---|
| 子女注册 → 直接用 | ✅ 已是一步步的表单 | 可拆成两页（先自己、再父母），每页少一点 |
| 设置父母手机 | ✅ 二维码 → 扫码 → 自动弹设置 | 无 |
| 长者三按钮 | ✅ | 无 |
| 协调员早上 | ✅「今天要处理」 | 无 |
| 警报处理 | ✅ 按钮顺序就是流程 | 可加"下一步建议"提示 |
| 新客人进来 | ⚠️ 要在三个标签间切换 | 做成一个"新客人向导"：五步一页一页走 |
| 照顾人报告 | ✅ 点选 + 拍照 | 无 |

要我接着做的话，优先做"新客人向导"和"注册分两页"，这两个最能减少协调员和子女的操作。
