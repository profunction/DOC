# 让手机 App 连上后端：三种方法

App 本身不带后端。登录页出现 "Unexpected token '<'" 或"请先填写服务器地址"，都是因为服务器地址为空或填错。

## 方法一：同一个 Wi-Fi，用自己的电脑当服务器（5 分钟，适合今天就想试）

1. 电脑上装 Node.js 22，然后：

```bash
cd server && npm install && npm start
```

2. 看电脑的局域网 IP（Windows 用 `ipconfig`，Mac 用 `ifconfig`），例如 `192.168.1.10`。
3. 手机和电脑连同一个 Wi-Fi，App 登录页"服务器地址"填 `192.168.1.10:8787`，点"测试连接"，显示"连接成功"后用演示账号登录。

要离开 Wi-Fi 也能连，在电脑上再跑一条隧道（任选）：`npx localtunnel --port 8787` 或 `cloudflared tunnel --url http://localhost:8787`，把它给的 https 网址填进 App。

## 方法二：Render 免费托管（15 分钟，有公网地址，适合给别人演示）

1. 把这个仓库推到你的 GitHub。
2. 到 render.com 注册，New → Blueprint，选这个仓库，Render 会读取 `render.yaml` 自动建好服务。
3. 部署完成后得到一个网址，例如 `https://anxin-care.onrender.com`，填进 App 的"服务器地址"。网站也在同一个网址。

注意：免费方案闲置会休眠，第一次打开要等约一分钟；重新部署会清空演示数据。正式使用请升级带持久磁盘的方案，并把环境变量 `SEED_DEMO` 改成 `0`。

## 方法三：自己的 VPS（正式上线用）

一台 2 核 4G 的 Linux 服务器加一个域名：

```bash
git clone <你的仓库> anxin && cd anxin
cp server/.env.example .env      # 填 JWT_SECRET、DATA_KEY、HOTLINE_PHONE，SEED_DEMO=0
docker compose up -d --build     # 网站 + API 在 8787 端口
```

前面用 Caddy 做 HTTPS（自动申请证书）：

```bash
sudo apt install caddy && echo "care.你的域名.com { reverse_proxy localhost:8787 }" | sudo tee /etc/caddy/Caddyfile && sudo systemctl restart caddy
```

App 的"服务器地址"填 `https://care.你的域名.com`。要一起跑手表服务器和推送，用 `docker compose -f docker-compose.yml -f docker-compose.stack.yml up -d --build`。

## 打包时写死服务器地址（用户就不用自己填）

```bash
cd web && VITE_API_BASE=https://care.你的域名.com npm run android:release
```

GitHub Actions 里则在仓库 Settings → Variables 设 `API_BASE`。
